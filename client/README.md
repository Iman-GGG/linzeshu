# 林则鼠微信小程序 · 本地开发说明

## 开发与调试

1. 用微信开发者工具打开本仓库的 `client` 目录作为小程序项目。
2. 在模拟器中预览各页面：
   - `pages/home` 首页
   - `pages/guide` 使用引导
   - `pages/camera` 劝烟相机（模拟器内多为 stub）
   - `pages/records` 本地劝阻记录

> **说明：** 当前客户端**没有**后端 `baseUrl` 配置文件（不存在 `utils/api.js`）。
> 劝烟记录与隐私同意状态使用微信本地存储；腾讯位置服务 Key 在 `utils/geo.js` 的 `TX_MAP_KEY`（可选）。

## 真机权限验证（必做）

相机、麦克风、相册与隐私相关能力**必须在真机上验证**，模拟器不能代替：

- **摄像头 / 麦克风：** `pages/camera` 录制劝烟过程（依赖设备 MediaRecorder 能力）
- **相册 / 图片：** 举报跳转与本地图片相关流程
- **隐私弹窗：** 首次启动的隐私说明（`app.js` → `showPrivacyModal`）

在真机预览前，请在微信开发者工具中勾选相应权限，并用测试机完整走一遍录制与授权拒绝路径。
